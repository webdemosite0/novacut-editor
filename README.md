# NovaCut Editor UI

Desktop-first video editing UI prototype built in Next.js App Router.

## Included

- Media browser with A-roll/B-roll organization
- Large preview monitor with playback controls
- Inspector for transform, color, motion, opacity and effects
- Multi-track timeline for captions, text, B-roll, A-roll, voice and music
- Colorful premium dark desktop UI
- Interactive tabs, media selection, playback state and controls

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope

This first version is the product UI shell. Real video decoding, timeline editing, media imports, waveform analysis, rendering/export, keyboard shortcuts and desktop packaging come next.
